# Homebrew Tap for Aura

Homebrew tap for [Aura](https://github.com/debugly/fsplayer), a multi-platform video player based on ijkplayer.

## Installation

```bash
brew tap debugly/aura
brew install aura
```

## Usage

Once installed, you can launch Aura from Spotlight or the Applications folder:

```bash
open -a Aura
```

## Uninstallation

```bash
brew uninstall aura
brew untap debugly/aura
```

## About Aura

Aura is a demo application for FSPlayer, featuring:
- Multi-format video playback (H.264, H.265, VP8, VP9, AV1, etc.)
- Audio codec support (AAC, MP3, Opus, FLAC, etc.)
- Hardware video decoding (VideoToolbox on macOS)
- Subtitle support (ASS, SRT, WebVTT, etc.)
- Cross-platform (iOS, Android, macOS)
